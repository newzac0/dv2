THIS VERSION OF THE GAME HAS BEEN ARCHIVED AND WILL NOT BE RECEIVING MORE UPDATES.

I began working on this game as a side project in high school, and at the time I was an extremely inexperienced programmer.
Many aspects of this project are janky or just flat out broken. The parts that do work are extremely lazy, bland, unintuative and so boring its not even enjoyable to play.
However I feel its important for me to keep as a way to see how far I have come as a developer.

A newer version of this game has been started from a fresh Unity project, mainly because I hate not using sprites I spent a ridiculous amount of time making go to waste.
If you're interested in a fanmade DragonVale game I highly suggest you go check out that game instead of this one as it is much more polished and contains more features!
